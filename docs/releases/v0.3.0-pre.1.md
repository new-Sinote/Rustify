# Rustify v0.3.0-pre.1 - Experimental uBOL build

> **Earlier experiment.** This is the first uBOL network-filtering pre-release, not the current adblocking implementation. Adblocking is now a first-class requirement on `feature/adblocking`, which adds native ad detection and a mute fallback. This build remains uncertified and its limitations still apply. See [ADR-0001](../ADR-0001-adblocking-direction.md) and [ADBLOCKING_RESEARCH.md](../ADBLOCKING_RESEARCH.md).

**Released:** 2026-11-26  
**Status:** Experimental pre-release. Not the default download. Not certified.  
**Asset:** `Rustify-0.3.0-x64-setup.exe` (NSIS, per-user install)  
**Based on:** [v0.2.0-pre.1](v0.2.0-pre.1.md)  
**Licence:** MIT for Rustify; GPL-3.0 for the bundled uBlock Origin Lite payload

## What this is

This build adds **uBlock Origin Lite 2026.1124.1811** to the existing `wry` + `tao` + WebView2 shell. The extension is unpacked into the install directory and loaded into the Spotify profile automatically. The default uBOL rulesets are active.

It is a separate pre-release because it changes the product's network behaviour. The certified 0.2.0 build remains the default download.

## What changed

- Bumped the app to 0.3.0.
- Bundled unmodified uBOL 2026.1124.1811 from the official Chromium release.
- The app now looks for `extensions\ublock` next to `rustify.exe`, in addition to `--ublock-ext` and `RUSTIFY_UBLOCK_EXT`.
- The player and chrome WebViews share one WebView2 environment when extensions are enabled.
- The installer shows the Rustify MIT licence and the uBOL GPL-3.0 licence, and installs `UBOL_LICENSE.txt` and `UBOL_SOURCE.txt`.
- The uninstaller removes the bundled extension and licence files.

## What it does not do

- **It does not guarantee an ad-free Spotify.** uBOL blocks many trackers and page requests. Spotify's audio path currently uses `spotifycdn.com` Fetch requests, and the test did not prove that audio ads are removed. Audio ads may still play.
- **It does not provide uBOL's settings UI.** WebView2 has no extension popup, badge, or dashboard host. Default filtering works; per-site switches, allowlists, and filter-mode controls are not available.
- **It does not auto-update uBOL.** The extension is pinned to 2026.1124.1811. Updating it requires a new Rustify build.
- **It is not certified.** The 0.2.0 memory, CPU, startup, and ad-row gates do not apply to this build.

## Certification and smoke test

This build has not been through the 35-minute playing soak, the 10-minute hidden/paused gate, or a full ad cycle. Do not treat it as certified.

## Risk and scope

- uBOL changes network requests. That is a different risk profile from the default build and may conflict with Spotify's terms.
- The build uses the same `%LOCALAPPDATA%\Rustify` profile as 0.2.0, so your Spotify session is preserved. Reverting to 0.2.0 leaves uBOL registered in the profile but does not load it.
- uBOL is GPL-3.0. The payload is unmodified and its source information is included in `UBOL_SOURCE.txt` and in the source archive attached to this release.
- The app remains unsigned and has no auto-update.

## Install

1. Download `Rustify-0.3.0-x64-setup.exe`.
2. Run it. The installer is per-user and does not require an administrator prompt.
3. Windows SmartScreen will warn because the binary is unsigned. Choose **More info -> Run anyway**.
4. Launch **Rustify** and sign in at `open.spotify.com`. uBOL is installed automatically.

**Requirements:** Windows 10/11 x64, the Evergreen WebView2 Runtime, and a Spotify account.

**Uninstall:** Settings -> Apps -> Rustify. The uninstaller asks whether to remove the local profile and settings. A silent uninstall keeps the data.

## Files and data

- Install directory: `%LOCALAPPDATA%\Programs\Rustify`.
- Bundled extension: `%LOCALAPPDATA%\Programs\Rustify\extensions\ublock`.
- App data: `%LOCALAPPDATA%\Rustify`.
- WebView2 profile: `%LOCALAPPDATA%\Rustify\WebView2` (shared with 0.2.0).
- Diagnostic log: `%LOCALAPPDATA%\Rustify\rustify.log`.
