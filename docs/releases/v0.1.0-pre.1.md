## What this is

The first public Rustify binary. It is a Tauri 2 + WebView2 host for the official Spotify Web Player (`https://open.spotify.com/`), built from the Phase 3 spike in [`spike/`](https://github.com/new-Sinote/Rustify/tree/main/spike).

It exists to prove the hard parts end to end:

- the official web player runs unmodified in WebView2;
- a free Spotify account can sign in and play;
- Widevine playback works on the tested Evergreen runtime;
- advertisements play to completion;
- audio continues when the window is minimized or hidden;
- the tray and Windows media-session integration work;
- top-level navigation can be restricted without breaking playback.

## What this is not

- **Not V1.** It has no Phase 4 memory policy, no auto-update, and no production polish.
- **Not ad-free.** Ads are served by Spotify and play normally. Nothing blocks, skips, mutes, or filters them.
- **Not a DRM or audio workaround.** The player uses Spotify's normal web playback path. No audio is extracted or re-streamed.
- **Not the measured baseline.** The measured memory host is `bench/wryhost`, not this Tauri spike. See [`docs/PERFORMANCE_RESEARCH.md`](https://github.com/new-Sinote/Rustify/blob/main/docs/PERFORMANCE_RESEARCH.md).

## What works

| Area | State |
|---|---|
| Official Spotify Web Player | Runs unmodified |
| Free-account sign-in | Verified with email/password |
| Playback | Verified; queue advances |
| Advertisements | Play to completion |
| Widevine | Works on the tested WebView2 runtime |
| Background playback | Continues when minimized or hidden |
| Tray | Show / Hide to tray / Quit; close hides to tray |
| SMTC | Playback status and metadata reported to Windows |
| Navigation allowlist | Spotify and the Cloudflare challenge only |
| Remote Tauri capabilities | None; `withGlobalTauri=false` |

Known limitation: social-login popups are blocked by the strict top-level allowlist. Email/password sign-in works.

## Install

1. Download `Rustify-Spike-0.1.0-x64-setup.exe`.
2. Run it. The installer is per-user and does not require an administrator prompt.
3. Windows SmartScreen will warn because the binary is unsigned. Choose **More info → Run anyway**.
4. Launch **Rustify Spike** and sign in at `open.spotify.com`.

**Requirements:** Windows 10/11 x64, the Evergreen WebView2 Runtime, and a Spotify account.

**Uninstall:** Settings → Apps → Rustify Spike. The WebView2 profile under `%LOCALAPPDATA%\com.rustify.spike` and the diagnostic log under `%LOCALAPPDATA%\RustifySpike` may remain; delete them manually for a clean profile.

## Performance expectation

This build does **not** include the `MemoryUsageTargetLevel.Low` lifecycle. The Phase 3/4 measurements for this shell were:

| State | PSS |
|---|---:|
| Paused, visible | 558.0 MB |
| Playing, visible | 594.8 MB |
| Playing, hidden | 603.0 MB |
| Hidden, paused after 5 minutes | 535.9 MB |

The wry benchmark host, with the memory policy, measured 60.5 MB paused after a re-trim and 206 MB playing after a re-trim. V1 will port the policy to Tauri and certify it with a periodic-trim soak. Do not judge V1 memory by this pre-release.

## Diagnostics and privacy

- The spike runs a **one-shot Widevine probe** after the first page load. It calls `navigator.requestMediaKeySystemAccess('com.widevine.alpha', …)`, reports the result through a cancelled navigation to `/__rustify_probe__`, and logs it. It does not modify playback, the page's audio path, or advertising.
- The app has **no telemetry**.
- The WebView2 profile is stored locally under `%LOCALAPPDATA%\com.rustify.spike`; the diagnostic log is `%LOCALAPPDATA%\RustifySpike\spike.log`.
- Spotify receives the same web-player traffic it would receive in a browser.
